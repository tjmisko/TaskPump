# G1.5 — Flip runner defaults: agent prefix, image, entrypoint

## Spec

Three runner-facing defaults:

1. **Agent prefix** `arachne-agent-` → `tp-agent-` (`pump-lib.sh:140
   apl_agent_prefix`, `tp-monitor:148`, docs). This is the name liveness
   enumeration matches on, so the CHANGELOG note from G1.3 (do not upgrade under
   a live drain) covers this flip too.
2. **Image** — `TASKPUMP_IMAGE` currently defaults to `arachne` (`tp-pump:99`).
   Remove the default: a *launch* (not `--dry-run`, which must keep working
   imageless) with no image configured exits with an error naming
   `TASKPUMP_IMAGE`. A wrong silent default is strictly worse than a loud
   missing one.
3. **Entrypoint** — `TASKPUMP_ENTRYPOINT` defaults to `/entrypoint-parallel.sh`,
   which is Arachne's image layout. Decide and document the shipped image
   contract in `docs/RUNNERS.md` (the natural answer: the claude-docker runner's
   own `entrypoint.sh` baked at a documented path, e.g. `/entrypoint.sh`), and
   point the default there. `examples/arachne.conf` pins
   `/entrypoint-parallel.sh` (G1.1).

## Scope

Defaults and their docs/tests. Renaming the *keys* is out of scope; the runner
contract itself does not change (that is G3). `test-pump-lib.sh`'s prefix
assertions flip to `tp-agent-` for the bare default and keep an arachne-pinned
case.

## Acceptance

- `apl_agent_prefix` with no env returns `tp-agent-`; with the arachne.conf pins
  returns `arachne-agent-` (both asserted).
- `tp pump --phases <p> --once` in a fixture with no image configured exits
  non-zero before any runner call, with `TASKPUMP_IMAGE` in the message;
  `--dry-run` in the same fixture still prints a full plan.
- `docs/RUNNERS.md` states the image contract for the shipped runner.
- `./tests/run-all.sh` green; golden suite under pins unchanged.
