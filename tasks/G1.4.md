# G1.4 — Flip identity and diagnostic defaults to TaskPump spellings

## Spec

Flip every default through which the tools *identify themselves* as Arachne:

- `TASKPUMP_COMMITTER_NAME`/`_EMAIL` defaults `arachne-task` /
  `task@arachne.local` → `tp-task` / `task@taskpump.local` (`tp-task:76-77`).
- `TASKPUMP_PROG_NAME` default `arachne-task` → `tp-task` (`tp-task:92`) — the
  prefix on every diagnostic.
- `tp-pump`'s hardcoded identities: the `warn()` prefix `arachne-pump:`
  (`tp-pump:206`), the plan header `arachne-pump plan` (`tp-pump:1168`), the
  transient systemd unit name/description `arachne-pump-*` (`tp-pump:1399-1402`),
  the `notify-send` title (`tp-pump:1385`), and the pkill hint (`tp-pump:1413`)
  → `tp-pump` spellings. Where these are not yet behind a key, follow
  `TASKPUMP_PROG_NAME`'s pattern rather than minting new keys.
- `tp-cleanup`'s snapshot committer `arachne-cleanup` /
  `cleanup@arachne.local` (`tp-cleanup:162`) → `tp-cleanup` spellings.
- `tp-monitor`'s Hyprland window class default `arachne-task`
  (`tp-monitor:1694`, `TASKPUMP_MONITOR_TASK_CLASS`) → `taskpump-task`.

## Scope

Identity strings only. The monitor frame title already defaults to the product
name (63ddcc9) — do not touch. Filenames are G1.3; agent prefix is G1.5. Golden
files that embed the plan header (`tests/golden/plan-*.txt`) are regenerated
here, in the same commit as the header flip.

## Acceptance

- `test-tp-task-generic.sh`'s bare-default diagnostic assertion (split in G1.2)
  now expects `tp-task: ` and passes.
- Golden plan files read `tp-pump plan — ...`; golden suite under the
  arachne.conf pins still byte-identical for the reference consumer.
- A ledger commit made in a scratch repo with no conf shows author
  `tp-task <task@taskpump.local>`.
- `./tests/run-all.sh` green.
