# G1.3 — Flip state, log, and note filename defaults to .taskpump-*

## Spec

Flip the default filename behind every state/log/note key from `.arachne-*` to
`.taskpump-*`, keeping the key names unchanged. The census (defaults live at):

- `TASKPUMP_PUMP_STATE_NAME` → `.taskpump-pump.state` (`tp-pump:202`,
  `tp-monitor:504`, `tp-dag-render:84`)
- `TASKPUMP_PUMP_LOG` → `<state dir>/.taskpump-pump.log` (`tp-pump:203`)
- `TASKPUMP_POOL_CAP_FILE` → `<state dir>/.taskpump-pool-cap` (`tp-pump:193`,
  `tp-disk-watchdog:52`)
- `TASKPUMP_USAGE_RESET_FILE` → `.taskpump-usage-reset` (`tp-pump:194`)
- `TASKPUMP_DISK_WATCHDOG_LOG` → `.taskpump-disk-watchdog.log` (`tp-pump:143`)
- `TASKPUMP_HOOK_MARK_FILE` → `.taskpump-fsguard.notified` (`tp-pump:142`)
- `TASKPUMP_AGENT_LOG_NAME` → `.taskpump-agent.log` (`tp-pump:134`,
  `tp-cleanup:58`, `tp-monitor:150`, `entrypoint.sh:148`)
- `TASKPUMP_BRIEF_OUT_NAME` → `.taskpump-phase-brief.md` (`tp-pump:135`)
- `TASKPUMP_RESUME_NOTE_NAME` → `.taskpump-resume.md` (`tp-pump:136`,
  `entrypoint.sh:152`)
- `TASKPUMP_GOAL_NOTE_NAME` → `.taskpump-goal.md` (`tp-pump:139`,
  `entrypoint.sh:150`)
- `TASKPUMP_RO_PROBE_FILE` → `.taskpump-rotest` (`entrypoint.sh:154`)
- `TASKPUMP_MONITOR_NOTES_DIRNAME` → `.taskpump-monitor-notes`
  (`tp-monitor:532`)
- `TASKPUMP_MONITOR_CACHE_BASE` → `$TMPDIR/taskpump-monitor` (`tp-monitor:509`)

The ledger lockfile is hardcoded with no key (`tp-task:332`,
`.arachne-task.lock`): give it `TASKPUMP_LOCK_NAME` with default
`.taskpump-task.lock`, bridge-compatible like every other key, and pin the old
name in `examples/arachne.conf` (extends G1.1's audit).

`entrypoint.sh:60` warns that renaming the agent log strands live agents. That
is an operational note for a running drain, not a blocker for the default:
restate it in CHANGELOG's 0.1.0 entry ("do not upgrade under a live drain").

## Scope

Default strings, the one new lock key, `taskpump.conf.example` census lines, and
doc cross-references. Suites updated where they assert the old default rather
than a pinned value. The env-bridge (`lib/config.sh`) needs no change — it is
name-generic.

## Acceptance

- `rg -i 'arachne' libexec lib runners gates hooks templates` reports no
  *filename default* — only legacy env-name fallbacks and prose comments.
- `./tests/run-all.sh` green; the golden suite (under the arachne.conf pins)
  byte-identical, proving the flip is config-shielded.
- A bare `tp pump --dry-run` in a scratch repo writes/names only `.taskpump-*`
  files.
