# G5.1 — Draft the F90 addenda for Arachne's ops ledger

## Spec

Two Arachne-side gaps surfaced by the 2026-08-12 exploration sit outside F90's
current task set. Write both as create-ready task texts (id, title, goal,
blockers, acceptance) in `docs/design/f90-addenda.md`, for filing into
Arachne's ops ledger with `arachne-task create`:

**F90.8 — Repoint the live host services.** `arachne-disk-guard.timer` is an
active systemd user timer execing `scripts/arachne-cleanup` roughly every five
minutes, outside any drain window, and `arachne-switchboard-recorder.service`
polls docker for containers by the `arachne-agent-` prefix. After F90.4 the
timer must exec the pinned taskpump checkout's `tp cleanup`, the prefix must
stay pinned in Arachne's `taskpump.conf` (the recorder's match contract), and
the swap must happen outside a drain window. Blockers: F90.4. Acceptance:
`systemctl --user cat` shows the new ExecStart; one full timer firing observed
clean in the journal; the recorder still attaches to a test container.

**F90.9 — Update the prep-long-session skill.** The skill's `allowed-tools`
frontmatter grants literal prefixes (`Bash(./scripts/arachne-pump
--dry-run*)`, `arachne-task list*`, `arachne-usage*`,
`run-parallel.sh --list`), and its orient step hard-gates on those scripts
existing — so the *permission grants*, not just paths, break on a clean
cutover, and its "path B" references (`run-parallel.sh`,
`parallel-manifest.tsv`) name files F90.1 deletes. Update grants and gate for
the shim paths now, with a note to re-point at bare `tp` after F90.7.
Blockers: F90.4 (shims exist); the tp-native re-point blocked on F90.7.
Acceptance: the skill runs end-to-end in a post-F90.4 checkout without a
permission prompt; no reference to deleted files remains.
