# G2.3 — Tag and push v0.1.0

## Spec

Cut the release Arachne's F90.4 pins its submodule to:

- `VERSION` → `0.1.0`; CHANGELOG's Unreleased heading becomes `0.1.0` with the
  date.
- `git tag -a v0.1.0` on the release commit; push `main` and the tag to origin.
- Under the contract's own semver rules this tag freezes the flipped defaults:
  any further default change is a MAJOR bump. That is the point of doing G1
  first.

## Scope

Version metadata and the tag. No code.

## Acceptance

- `git ls-remote --tags origin` shows `v0.1.0`.
- `VERSION`, the CHANGELOG heading, and the tag agree.
- Arachne's F90.4 is notified (a comment in its ops task or the handoff thread)
  that its "no release tag" blocker is cleared — G5.2 picks up from there.
