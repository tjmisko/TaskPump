# G5.2 — Re-verify the F80 dry-run equivalence against tagged v0.1.0

## Spec

Arachne's 2026-08-12 handoff (`ops/planning/handoffs/2026-08-12 19:17 -
f80-via-taskpump-rebinding.md`) recorded that `tp task ready --phases F80`
matches Arachne's own output and `tp pump --phases F80 --dry-run` is
byte-identical from six config lines — but against the pre-tag working tree.
Re-run the comparison against what F90.4 will actually pin:

- In the Arachne checkout, with `tp` resolved from the tagged v0.1.0 tree and
  the full `examples/arachne.conf` (not the six-line subset) as
  `taskpump.conf`, capture `tp task ready --phases F80` (table and `--json`)
  and `tp pump --phases F80 --dry-run`.
- Byte-diff each against the `scripts/arachne-*` equivalents at Arachne's
  current HEAD.
- Any diff is triaged to a named default flip and either accepted (a pin was
  meant to change it — then arachne.conf or the acceptance here is wrong and
  one of them gets fixed) or fixed before Arachne's F90.5 canary runs.

## Scope

Read-only verification plus a written record. No changes to Arachne beyond the
temporary conf copy; no live pump run — `--dry-run` only.

## Acceptance

- The comparison record (commands, tag sha, Arachne HEAD sha, verdict per
  command) is appended to the handoff's thread in Arachne's ops repo.
- Verdict is byte-identical for all three captures, or every diff line is
  traced to its G1 task and resolved.
- Arachne's F90.4/F90.5 tasks are commented with the result.
