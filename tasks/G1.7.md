# G1.7 — Drop the Rust and host-hardware defaults

## Spec

Remove the assumptions that the driven project is Rust and the host is this
Apple-Silicon machine:

1. **Verify commands** — `TASKPUMP_VERIFY_CMDS` defaults to
   `cargo fmt --all` / `cargo clippy ... -D warnings`. New default: empty. The
   phase-drain brief template must render cleanly with an empty verify block
   (no dangling "leave these green:" heading over nothing) — extend the
   renderer-contract tests for the empty case.
2. **Disk reclaim** — correction from G1.1's audit: `TASKPUMP_RECLAIM_CMD`'s
   default is already empty (`tp-pump:178`); the cargo behavior is the
   *built-in empty-case fallback* in the reclaim path, not a default string.
   The flip therefore changes built-in behavior: when the key is unset, the
   per-tick reclaim pass becomes a no-op that logs one line saying it is
   unconfigured, instead of falling back to cargo. `tp-cleanup`'s
   cargo-specific `target/` logic runs only when a reclaim command is
   configured; its `--include-primary` comment naming Arachne is rewritten
   while there.
3. **net-health gate** — `TASKPUMP_HEALTH_GATE` default `1` → `0`. The gate
   stays shipped (its detection logic is a worked example of a real gate) but is
   opt-in; `docs/GATES.md` moves it from "the default chain" to "shipped,
   consumer-enabled", keeping the brcmfmac incident story. The default chain
   becomes token-fresh → usage → disk-low.

`examples/arachne.conf` already pins all three ways Arachne wants them
(G1.1 verifies: `TASKPUMP_VERIFY_CMDS`, `TASKPUMP_RECLAIM_CMD='cargo clean'`,
`TASKPUMP_HEALTH_GATE=1`).

## Scope

Defaults, template empty-case rendering, gate-chain composition, GATES.md. The
gate executables themselves do not change behavior.

## Acceptance

- A brief rendered with no verify commands contains no verify section, asserted
  by the renderer-contract suite.
- `tp pump --dry-run` in a scratch repo shows the three-gate default chain;
  with arachne.conf pins it shows all four, net-health first.
- Reclaim pass with `TASKPUMP_RECLAIM_CMD` unset touches nothing and logs the
  unconfigured line (cleanup suite).
- `./tests/run-all.sh` green; golden suite under pins unchanged.
